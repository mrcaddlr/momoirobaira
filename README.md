# Momoirobara

A cute, lightweight local music player with a kawaii-inspired interface.

## Features

- Local music library with remembered songs
- Folder and file importing
- Playlists and favorites
- Metadata and embedded artwork support
- Lyrics support
- Last.fm integration
- Theme customization
- Persistent library storage in the browser
- GitHub Pages deployment

## Running

Momoirobara is a web app. Open the deployed GitHub Pages site or run the files from a local web server.

## Persistence

Imported music is stored locally in the browser using IndexedDB. Browser-local storage does not sync music between different devices or browsers.

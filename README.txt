Momoirobara

Run:
  ./Momoirobara

This launches Momoirobara in Google Chrome app mode. The launcher checks the Flatpak Google Chrome installation first, then regular Chrome/Chromium installs.

Imported local music is stored in the browser IndexedDB and restored between launches. Metadata and embedded artwork are read from the imported files when available. Lyrics are fetched from LRCLIB.
